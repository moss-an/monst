# モンスト ステータス計算ツール

モンスターのステータス（攻撃力・スピード）と許容範囲、上限数、モンスポット、使用する等級を指定し、条件を満たすわくわくの実の組み合わせパターンを逆算・一覧表示するツールです。

## ファイル構成

```text
monst/status-calc/
├── index.html        # メイン画面
├── README.md         # 本ドキュメント
└── ts/
    ├── app.ts        # 状態管理・UI操作制御
    ├── logic.ts      # 組み合わせ探索・ステータス計算ロジック
    └── constants.ts  # わくわくの実・モンスポット加算値マスタ定義
```
