# モンスト ステータス計算ツール

モンスターのステータス（攻撃力・スピード）と許容範囲、上限数、モンスポット、使用する等級・わくわくの実の種類を指定し、条件を満たすわくわくの実の組み合わせパターンを逆算・一覧表示するツールです。

## ファイル構成

```text
monst/status-calc/
├── index.html        # メイン画面
├── README.md         # 本ドキュメント
└── ts/
    ├── app.ts        # 状態管理・UI操作制御
    ├── logic.ts      # 組み合わせ探索・ステータス計算ロジック
    ├── constants.ts  # アプリケーション共通定数・エラーメッセージ
    ├── fruits.ts     # わくわくの実マスタ定義と自動生成ロジック
    └── spots.ts      # モンスポットマスタ定義
```

## わくわくの実マスタのメンテナンス方法

`ts/fruits.ts` の `FRUIT_CATEGORY_MASTER` に配列要素を追加・編集するだけで、型定義・UIの選択ボタン・計算ロジックのすべてに自動反映されます。
