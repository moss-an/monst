# モンスト ランク計算ツール

「モンスターストライク」のクエスト周回における、ランク・経験値シミュレーションツールです。

現在のランクから目標のランクまでに必要な周回数や推定所要時間を簡単に計算できます。

## 主な機能

1. **ランク・経験値の相互変換と検証**
   - 現在・目標のランク、または累計経験値を自由に入力してシミュレーション可能。
   - ランクと累計経験値が相互に自動計算・反映されます。
   - 入力値のバリデーションをリアルタイムで実行します。

2. **獲得経験値倍率の細やかな設定**
   - **基本倍率**: 学びの力 / モンスポット / キャンペーン
   - **詳細設定**: 経験値アップモンスター / 運極ボーナス / マルチプレイ / カスタム倍率
   - 上記の要素を組み合わせて合計倍率を自動算出します。

3. **クエスト設定と周回シミュレーション**
   - プリセットの選択、または基礎獲得経験値のカスタム入力に対応。
   - 1周の平均クリア時間(秒)を設定することで、目標達成までの推定所要時間(日・時間・分)を自動計算します。

```text
monst/rank-calc/

```

## CSVファイルのデータ構造・仕様

データ更新やメンテナンス時は、`csv/` 配下の各ファイルを以下のフォーマットに沿って編集してください。

### 1. `rank_table_1_999.csv`

ランク 1〜999 までの到達時点における累計経験値を定義するファイルです。

この区間は上がり幅が漸増しているため、CSVファイルから直接取り込んでいます。

- **フォーマット例**

  ```csv
  rank,total_exp
  1,0
  2,100
  3,250
  ```

- **列構成**
  - `rank`: ランク(1〜999)
  - `total_exp`: そのランクに到達した時点の累計経験値(`rank 1` は `0`)

### 2. `rank_step_table.csv`

ランク999以降の「1ランク上げるために必要な経験値」を区間ごとに定義するファイルです。

この区間は上がり幅が段階的に固定値のため、ツール内で計算処理をしています。

- **フォーマット例**

  ```csv
  minRank,maxRank,expPerRank
  999,1499,1443627
  1500,1999,4330881
  2000,2499,12992643
  2500,,51970572
  ```

- **列構成**
  - `minRank`: 区間の開始ランク
  - `maxRank`: 区間の終了ランク (末尾行のみ空欄でも可)
  - `expPerRank`: 1ランク上昇に必要な経験値

- **末尾行について**
  - 末尾行のみ、`maxRank`は空欄を許容します。
  - 上記例の4行目は、`2500,,51970572`, `2500,2999,51970572` のいずれでも「ランク2500以降は1ランクあたり51,970,572 Expを適用する」という設定になります。

## 技術スタック

- **フロントエンド**: HTML5, JavaScript (ES Modules)
- **フレームワーク**: Vue.js 3 (CDN / ES Module形式)
- **スタイリング**: Tailwind CSS (CDN)

## 使い方

1. リポジトリのファイルをWebサーバーまたはローカル環境に配置します。
2. `index.html` をブラウザで開きます(`fetch` APIを使用しているため、Webサーバーまたはローカル開発サーバー(VS Code Live Server等)環境での閲覧を推奨します)。
3. 「1. ランク設定」で現在のランク/経験値と、目標のランク/経験値を入力します。
4. 「2. 獲得経験値倍率設定」でお使いの学びの力やスポット、各種倍率を選択します。
5. 「3. クエスト・タイム設定」で対象のクエストと1周の平均時間を入力します。
6. 最下部の「計算結果」に、必要な総経験値・1周あたりの獲得経験値・周回数・所要時間が自動で表示されます。
