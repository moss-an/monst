# モンスト ランク計算ツール

モンスターストライクのクエスト周回における、ランク・経験値シミュレーションツールです。

現在のランクから目標のランクまでに必要な周回数や推定所要時間を簡単に計算できます。

## 主な機能

1. **ランク・経験値の相互変換**
   - ランクまたは累計経験値を自由に入力してシミュレーション可能。
   - ランクと累計経験値は相互に自動計算されます。
   - 将来的なランク解放に備えて、経験値テーブルを一部編集できます。

2. **獲得経験値倍率の設定**
   - **基本倍率**: わくわくの実 / モンスポット / キャンペーン
   - **詳細設定**: 経験値アップモンスター / 運極ボーナス / マルチプレイ / カスタム倍率
   - 上記の要素を組み合わせて、合計倍率が自動算出されます。

3. **クエスト設定と周回シミュレーション**
   - 基礎獲得経験値は、クエストプリセットの選択とカスタム入力に対応。
   - 1周の平均クリア時間(秒)を設定することで、目標達成までの推定所要時間(日・時間・分)が自動計算されます。

## 使い方

1. `1. ランク設定`で現在のランク/経験値と、目標のランク/経験値を入力します。
2. `2. 獲得経験値倍率設定`でわくわくの実やモンスポットほか、各種倍率を選択します。
3. `3. クエスト・タイム設定`で対象のクエストと1周の平均時間を入力します。
4. 最下部の`計算結果`に、諸情報が自動で表示されます。

## CSVファイルのデータ構造・仕様

データ更新やメンテナンス時は、`csv/` 配下の各ファイルを以下のフォーマットに沿って編集してください。

いずれのCSVファイルも先頭行はラベルとして記載しており、ツールには取り込まれません。

### 1. `rank_table_1_999.csv`

ランク1〜999までの、到達時点における累計経験値を定義するファイルです。

この区間は上がり幅が漸増しているため、CSVファイルから直接取り込んでいます。

- **フォーマット例**

  ```csv
  rank,total_exp
  1,0
  2,26
  3,137
  4,363
  ```

- **列構成**
  - `rank`: ランク(1〜999)
  - `total_exp`: そのランクに到達した時点の累計経験値

### 2. `rank_step_table.csv`

ランク999以降の、1ランク上げるために必要な経験値を区間ごとに定義するファイルです。

この区間は上がり幅が段階的に固定値のため、ツール内で計算処理をしています。

- **フォーマット例**

  ```csv
  minRank,maxRank,expPerRank
  999,1499,1443627
  1500,1999,4330881
  2000,2499,12992643
  2500,,51970572
  ```

- **列構成**
  - `minRank`: 区間の開始ランク
  - `maxRank`: 区間の終了ランク
  - `expPerRank`: 1ランク上昇に必要な経験値

- **末尾行について**
  - 末尾行のすべての列の値が埋まっていたら、`maxRank`を超えるランク帯でも`expPerRank`が適用されます。
  - 末尾行のみ、`maxRank`は空欄を許容します。空欄の場合は上限なしの状態として扱われます。
  - 末尾行のみ、`expPerRank`は空欄を許容します。空欄の場合は1行前の値が引き継がれて処理されます。
  - 上記例の末尾行は、`2500,,51970572`, `2500,2999,51970572` のいずれでも`ランク2500以降は1ランクあたり51,970,572 Expを適用する`という設定になります。
