# モンスト ランク計算ツール

モンスターストライクのクエスト周回における、ランク・経験値シミュレーションツールです。

現在のランクから目標のランクまでに必要な周回数や推定所要時間を簡単に計算できます。

## 主な機能

1. **ランク・経験値の相互変換およびランク上限解放時の必要経験値設定**
   - ランクまたは累計経験値を自由に入力してシミュレーション可能。
   - ランクと累計経験値は相互に自動計算されます。
   - 将来的なランク解放に備えて、経験値テーブルを一部編集できます。

2. **獲得経験値倍率の設定**
   - **基本倍率**: わくわくの実 / モンスポット / キャンペーン
   - **詳細設定**: 経験値アップモンスター / 運極ボーナス / マルチプレイ / カスタム倍率
   - 上記の要素を組み合わせて、合計倍率が自動算出されます。

3. **クエスト設定と周回シミュレーション**
   - 基礎獲得経験値は、クエストプリセットの選択とカスタム入力に対応。
   - 1周の平均クリア時間(秒)を設定することで、目標達成までの推定所要時間(日・時間・分)が自動計算されます。

## 使い方

1. `1. ランク設定`で現在のランク/経験値と、目標のランク/経験値を入力します。
2. `2. 獲得経験値倍率設定`でわくわくの実やモンスポットほか、各種倍率を選択します。
3. `3. クエスト・タイム設定`で対象のクエストと1周の平均時間を入力します。
4. 最下部の`計算結果`に、諸情報が自動で表示されます。
